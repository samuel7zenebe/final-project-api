# Backend — Final Project API

## Overview

RESTful API backend for the Final Project application. Built with **Express.js 5** and **TypeScript**, using **Neon (serverless PostgreSQL)** as the database via **Drizzle ORM**, **Cloudinary** for image storage, **Upstash Redis** for caching, and **JWT** for authentication. API documentation is served automatically via Swagger UI.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Runtime | Node.js |
| Language | TypeScript |
| Framework | Express.js v5 |
| Database | PostgreSQL (Neon Serverless) |
| ORM | Drizzle ORM |
| Caching | Upstash Redis |
| Image Storage | Cloudinary |
| Authentication | JSON Web Tokens (JWT) + bcrypt |
| Validation | Zod |
| File Uploads | Multer (memory storage) |
| API Docs | Swagger (swagger-jsdoc + swagger-ui-express) |

---

## Prerequisites

- **Node.js** v18 or higher
- **npm** (or **bun**)
- A [Neon](https://neon.tech) PostgreSQL database
- A [Cloudinary](https://cloudinary.com) account
- An [Upstash](https://upstash.com) Redis instance

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Copy the example file and fill in your values:

```bash
cp .env-example .env
```

See the [Environment Variables](#environment-variables) section for all required keys.

### 3. Run in development

```bash
npm run dev
```

The server starts at `http://localhost:5000` by default (or the `PORT` you set).

## API Endpoints

Interactive API documentation is available at:
```
http://localhost:5000/api-docs
```

### Health

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Health check — returns `{ status: "OK", timestamp }` |

### Users

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/user` | Returns a list of users |

### Posts

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/posts` | Create a new blog post with an optional featured image upload (`multipart/form-data`, field: `image`) |

> **Image upload constraints:** images only, max **5 MB**. Images are resized to 1200×630 and stored on Cloudinary.

## Environment Variables

Create a `.env` file in the project root. All variables below are required unless marked optional.

```env
# Server
PORT=5000

# PostgreSQL — Neon Serverless
DATABASE_URL=postgresql://<user>:<password>@<host>/<db>?sslmode=require

# Cloudinary
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
CLOUDINARY_FOLDER=blog_images   # Optional — defaults to "blog_images"

# Upstash Redis
UPSTASH_REDIS_REST_URL=https://your-redis-url.upstash.io
UPSTASH_REDIS_REST_TOKEN=your_redis_token

# JWT / Auth
JWT_SECRET=your_jwt_secret
ACSESS_TOKEN_SECRET=your_access_token_secret
REFRESH_TOKEN_SECRET=your_refresh_token_secret
SALT=10   # bcrypt salt rounds
```

## Database Migrations (Drizzle Kit)

Generate and apply migrations using Drizzle Kit:

```bash
# Generate migration files
npx drizzle-kit generate

# Push schema directly to the database (no migration files)
npx drizzle-kit push

# Open Drizzle Studio (DB GUI)
npx drizzle-kit studio
```
